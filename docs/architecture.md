# 当前架构与兼容范围

年度报告是主入口，书籍蒸馏可选。安装后的操作以`reading-yearbook-skill/SKILL.md`和`references/standard-delivery.md`为准；本文件供开发维护，不复制用户操作说明。

## 当前链路

- 年鉴：generate_reading_html采集／复用同一账号年份缓存；build_reading_html规范化、排除私密材料、处理封面与字体，生成单文件HTML。
- 分享：reading-app管理选择与预览，reading-share-state保存本地编辑引用，reading-share-art同时绘制预览与下载PNG。数量来自实际公开书目；PNG保存当前预览，ZIP保存所选页。
- 蒸馏：ebook_light处理正文或有界公开资料，distillation_result校验结果，report_reader生成阅读区，reading_delivery追加到当前报告或生成独立阅读页。蒸馏只提供复制、Markdown和HTML，不提供分享图。
- PDF与Markdown：使用当前版本的完整阅读小册与档案导出逻辑，不把屏幕筛选误当用户删书。

## 不应破坏的约定

1. 未取得、确认零记录与接口不支持分开处理。没有笔记、封面或蒸馏结果也能交付报告；不虚构书评、日期、每日时长或用户感受。
2. 年度口径与当前进度分开，私密材料不进入HTML、图像和文档。授权Key、整书和中间任务只留私人目录。
3. 年历按UTC日期运算，周一开始；自动处理365／366天和54列年份。明细缺失不等于零，未来单独标识，不用月度总量反推热度。
4. 编辑选择与阅读材料分开。浏览器保存随机作品ID、比例、页ID和选句来源／指纹，不保存原文或密钥。更新复用有效引用，清空也是有效选择；存储失败不阻止导出。
5. 单文件内嵌字体、代码与艺术资源。局部修复保持当前UI和画布基准；预览与导出共用渲染器。

## 历史工程

run_share、旧deck／拼贴示例、run_yearbook私人档案和旧深度蒸馏引擎用于既有工程／缓存兼容，不是新任务默认入口。它们仍有测试与恢复调用，本次不直接删实现。更改发行范围前先检查实际调用，并单独验证旧数据读取。

早期视觉探索、阶段计划与验收稿不作为当前产品约定。原记录可从GitHub的2127ee1及更早提交查询。仍有价值的视觉方法保存在Skill references；字体OFL、lieflat-charts许可与第三方来源清单继续随包保留，不因清理开发文档删除。

## 开发与发行边界

根目录docs和tests不属于Skill运行资源。skill_release维护资源指纹与安装校验；本机依赖、私人输入、缓存和输出均不发布。发行包中的历史样例体积另行评估，本次保持兼容，不借文档整理重写UI或更换渲染器。

## 安全约定

- 微信读书授权仅从环境变量读取，通过HTTPS发送给固定官方网关。网关不跟随重定向，不回显服务端任意错误正文，响应大小受限。封面只接受指定官方HTTPS域名与标准端口，每次跳转重新校验。
- 年鉴和独立阅读页在输出前检查密钥；命中时停止写入，不回显原文。数据字段白名单、HTML转义和脚本JSON转义共同阻止把材料当作代码执行。私密书目及关联材料不进入公开报告。
- 静态预览只监听127.0.0.1，校验Host、Origin与跨站子资源请求，不提供目录、API或任意文件下载。响应禁止嵌入、携带来源信息及脚本发起网络请求。可写蒸馏工作台另用随机令牌、独立助手令牌与同源校验。
- .env、凭据文件、正文、账号缓存和任务状态不进入Git。私人输出放在用户工作目录，不写入Skill安装目录。HTML仍可能包含用户保留的公开书目和个人想法，分享前应检查；私密过滤不等于匿名化。
- EPUB展开体积、路径、上传大小和模型执行预算均有限制；不执行书籍或网页中的指令。可选模型CLI无工具权限，不把Key放进进程参数。

这些是应用边界，不替代设备访问控制。持有本机账号权限的其他程序仍可能读取本地文件；正文交给用户所选的宿主模型服务处理，不宣称离线推理。安全验证使用合成数据，不调用真实账号，也不把扫描通过称为不存在任何漏洞。
