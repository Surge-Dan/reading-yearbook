# 年年阅

把真实阅读材料整理成可浏览、可导出的HTML年鉴。组图、主题书单和单书卡都是该年鉴分享画布的输出；网页预览和PNG使用同一个ReadingShareArtwork渲染器。沿用当前已认可的纸本方向，按实际数据组织书卡；改变艺术方向需单独确认。

## 路由

- 年度报告是核心：用户说“打开年年阅／生成报告”时，直接读[HTML年鉴操作](references/html-yearbook.md)，复用真实阅读数据生成、查看与导出，不要求先蒸馏。已有有效精华可通过可重复的 `--distillation <distillation.json>` 附在报告底部；没有就隐藏该区域，不弹窗催用户。显式提供的坏包、失败任务或真实／示例混用仍拒绝。蒸馏书目不自动加入年度已读书单或改变统计。用户不填 JSON、不运行命令；只要图片时复用现有报告选页。
- 按书名蒸馏／提供电子书／开始蒸馏：这是可选功能。读[书籍蒸馏](references/distillation-method.md)与[轻量笔记](references/light-reading.md)，助手接收书名或正文路径，读取后一次综合成短笔记并保存有效 `distillation.json`。新任务默认不做能力卡、RIA、压力测试或独立书评调用。同名书在对话确认；仅书名身份与资料阶段有界联网。宿主须能共享文件、运行 Python 与访问本机私有服务，书名模式还需联网工具；纯聊天／不共享文件的宿主不承诺可用。正文交给当前模型服务，高成本先确认，不自动重试长书或切换模型。网页只负责阅读和导出，不承担上传或模型连接。独立蒸馏无需微信读书或年度记录。
- 初次使用先核查安装目录必需资源及`requirements.txt`依赖，由助手补齐；`skill_release.py`提供发布清单校验与完整本地同步。不能因仓库里的示例网页能打开，就认为已安装Skill可独立运行。Noto字体资源与OFL许可保留；默认沿用已认可的本机字体优先策略，不自动替换或内嵌新字族。
- 年度排行最多10项且过滤不足5分钟的条目，不作为完整书单接口。候选扩查先检查新请求预算；历史年结合真实完成日期与年内笔记证据，最近阅读时间不能证明此前没读过。覆盖不足交付部分年鉴并说明。`--refresh all`用于用户要求重新同步，视觉修订仍复用材料。
- HTML图表按数据问题组织，保留lieflat-charts来源与许可。当前认可方向为月度细线、分类书脊、逐书时长横条与滚入／重播动画；用户指定参考图时连同字体、原创素材、纸面层次和实际导出一起还原。分类显示真实本数，时长不当进度；缺少逐日数据不制作每日热力图。
- 年度回包有逐日、时段、分类时长或读／听分布时保留对应数据；默认页面仍采用原有模块，新增图表布局需单独确认，不为凑模块扩大采集。年度时段数组从6点开始，先转换到0—23点。电子书与有声专辑保留类型；有声内容无个人笔记接口时明确“未提供”，不能说已核查为零。
- 没有划线、个人笔记或蒸馏结果也能生成和阅读报告。仅有笔记时展示个人想法；都没有时保留真实书架和统计。请求失败标为未取得，不能伪装成零记录；缺时间不猜时间线，年度零书目与独立蒸馏结果可以并存。HTML不自动全文检索，书评来自助手已完成的结果。
- HTML优先补齐每本已确认书籍的真实封面、当前进度、完整划线和个人想法；组图中的精选摘录不能代替完整采集。封面缺失或损坏时自动使用统一的书名／作者占位，正常生成、重建和打开年鉴，不因此拦住统计、笔记或分享，也不自动改为草稿。保留有效真实封面，不删书、不伪造封面或用不同版本凑数；可在既有授权／预算内补采，不能为图片无限重试。缺图记入材料状态而非阻断报告；只有明确要求全部真实封面时才用`--require-all-covers`严格检查。核查后为零与采集失败分开显示；年度汇总和当前阅读进度分别保留口径。
- HTML分享出口包含封面、阅读统计、阅读分布、阅读时间线及全部已载入书籍，不受精选标记限制。默认全部勾选，允许取消；书目、已选数量和总页数随当前用户数据计算，不能照搬示例数字。书籍多选支持搜索、独立预览和撤销；ZIP页数须与当前勾选一致。无划线或笔记仍可导出阅读信息卡，零书目保留四张概览的真实空态。
- 分享画布按材料组织字体、图表、书封、侧栏与原创元素，不能固定为标题＋书封＋一句话。短摘录、长摘录、有笔记与无笔记采用不同信息结构，数据丰富度决定图表，不按书籍类别猜观点。使用同一绘制入口预览与导出，先做代表样张及375px阅读预览，字体或风格调整后再次检查真实图片。
- 只做书单或单书分享：仍读[HTML年鉴操作](references/html-yearbook.md)，确认本次书目、材料与比例，使用网页的分享渲染器。旧run_share.py、deck和material-led工程只用于明确指定的历史工程维护，不作为新任务或图片任务的默认入口。
- 用户明确要求改变艺术方向时，才定向读[艺术指导](references/art-direction.md)、[拼贴方法](references/collage-method.md)或[字体方法](references/typography.md)。这些历史设计资料只提供参考，不能触发另起一套渲染流程。
- 改一页：只读现有年鉴、该页材料与HTML年鉴操作的对应段，不重跑调研或采集。分享图的字体、间距或比例有问题时读[排印修正](references/share-typography.md)，检查实际PNG及全部书卡。用户要求微调时，以最近认可的实际HTML／PNG为视觉基准，锁定字体、插画、纸面、配色、构图及渲染方式；只修改明确提出的局部问题，数据与逻辑修复不能顺带换主题、内嵌不同字体或新增布局模块；按钮配色仅调整控件，不修改图表和装饰共用的色彩变量。分享图延续网页风格，不能借局部修正另起一套视觉。
- 已认可UI的维护：用户要求保留界面时，修复范围只包含数据、缓存、错误处理及内部逻辑。保留当前控件、模块、弹窗、字体、颜色、间距和交互入口；新增切换、排除、放大预览等可见功能属于候选建议，不随常规修复默认加入。
- 真实数据尚未采集：才读 [微信读书接口](references/weread-api.md)。已有数据直接复用。
- 用户明确要完整私人档案或图谱：读 [档案交付](references/output-contract.md)，使用原 `run_yearbook.py`；不默认扩展分享任务。
- 调整原始数据字段时才读 [数据契约](references/data-contract.md)；证据分级细节见 [证据规则](references/evidence-rules.md)。

## 确认与交付

1. **范围**：复用已给出的年份、比例与书目，只询问缺失选择。HTML默认载入已核实书目；分享默认四张概览＋全部载入书籍，不限定3–5本。主题书单或单书任务按用户范围选页。网页内置比例为1:1、3:4、4:5，自定义尺寸属于额外开发，不能承诺现成支持。
2. **预览**：已有认可网页直接沿用，不重新提供两个方向。首次任务展示网页与代表分享卡，至少涵盖本次存在的材料类型；有划线、只有笔记、无笔记分别检查，比例变化核对实际画布。当前示例见[示例说明](examples/README.md)，不能将历史独立组图当作默认样式。
3. **导出**：使用网页内同一画布生成单张PNG或选定页面的ZIP；PDF通过浏览器打印保存，Markdown和JSON保留已载入资料。预览和下载必须与当前内容一致。确认绑定当前展示版本，不能用旧图代替或自动记为用户同意。

默认交付可离线打开的单文件HTML。仅要图片时交付选定PNG，不默认交付旧deck工程。助手维护数据，用户无需填写JSON；缺少浏览器控制环境时保留可导出的HTML并说明尚未代为下载，不能宣称PNG已经生成。浏览器内导出不要求用户安装Playwright。

## 常用命令

在Skill目录执行，Windows使用`python -X utf8`。年份与输出路径按当前任务调整。

```powershell
python -X utf8 scripts/generate_reading_html.py --year 2026 --distillation output/books/已完成任务/deep/distillation.json --output output/reading-2026/index.html
python -X utf8 scripts/build_reading_html.py --input 已有材料.json --distillation output/books/已完成任务/deep/distillation.json --year 2026 --output output/reading-2026/index.html
python -X utf8 scripts/skill_release.py
python -X utf8 scripts/serve_ebook.py --output output/books --runner agent --port 0
```

## 内容与成本边界

- 生成报告时，助手按[阅读人格规则](references/reading-personality.md)分析本年个人想法和主动划线，生成可追溯的 reading_signals 并随数据交给构建器。网页只展示全年阅读侧写；依据不足的维度不显示比例。分析使用当前助手，不额外调用模型 API。

- 新蒸馏默认按[轻量笔记](references/light-reading.md)组织概览、少量核心观点、启发、可靠金句与短书评，约1200–1800字为参考。人物关系、逻辑线、作者主张融入内容，不再逐项扩成独立栏目；语气随书调整，保留具体例子和自然趣味。旧结果保持可读，不擅自删除或改写。

- `reading_lenses` 与 `memorable_passages` 有内容才展示，视角标题随书选择，例如“这本书在意什么”“书中透露出的底色”“读完想试的一件事”。金句必须逐字匹配原文与精确来源，书名模式只允许原书公开试读，不把二手转述或自写句子当作者引文。网页、复制、Markdown、独立HTML与PNG/ZIP使用同一本所选结果，页尾保留资料范围。旧结果无新字段时正常阅读，不生成占位内容。

- 轻量结果隐藏空栏目。正文分段只读一轮，最后综合时一并写[短书评](references/book-review-writing.md)，不额外调用；书名目录仅作资料线索，不凭目录或记忆补写整书。必要的来源／引用检查、缓存身份与安全恢复保留，不以精简为由伪造覆盖或验证状态。

- 引用保留来源，个人想法、AI 精华与内容简介分开标注，不凭模型记忆补写全书或用户感受。书名模式只读取有限公开资料，所有导出注明“未核验全文”；二手转述不当原书引文，不自动检索或下载全文。整书模式仅分析用户提供有权处理的正文。决策速查与章节索引从同一分析对象派生，不能新增未经支持的方法或把演练说成原书案例。
- 默认电子书由当前助手的模型服务处理，消耗宿主账号额度，不是完全离线计算。可选 CLI 才调用本机 Codex/Claude。当前 Agent 无独立盲测上下文，方法状态至多 needs_review；不得把同会话演练称为已证明任务增益。不另行上传第三方存储或自动发布；核验状态和覆盖缺口保留在全部导出。
- Key只来自环境变量，不进对话、日志或交付；不上传阅读记录，不自动发布。示例明确注明虚构，不能用于填补真实用户的缺失数据。
- 年鉴说明一次时间范围，采集日期集中放来源区。区分未取得与核查为零、年度汇总与当前阅读进度、已载入与完整全年覆盖。
- 默认单个助手，只加载当前流程需要的材料。修订复用数据与图片，只处理受影响页面。生图、扩大调研或改变艺术方向先说明工作范围，不自动串联多个设计Skill。
- 只报告实测验证和实际文件；字体、排版与审美仍需看实际样张，不编造token节省率或保证任意用户数据都已验证。
