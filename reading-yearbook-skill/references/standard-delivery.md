# 标准页面与助手交付流程

## 默认成品

当前发行包的 `reading-template.html`、`reading-app.css`、`reading-refinement.css`、`reading-art.css`、`reading-share-art.js`、`ebook-reader-section.html` 和 `ebook-app.*` 是统一视觉实现。生成、追加、独立阅读与文档导出都复用它们，不在输出HTML里临时追加一套主题，不借用历史gallery，不根据用户书单另行设计页面。

保留纸色、字体、插画、标题层级、图表尺度、圆角、弹窗关闭方式、间距、分享画布、红色导航与暖橙操作。不同用户只替换本人数据；书目、长标题、分类数量、缺数据和未知时长按内置规则适配，不能复制演示数字、人格结果、书评或封面。字体随设备可能有回退，不能保证所有系统逐像素一致。

年度文档用专用PDF小册版式与分层Markdown；网页不展示JSON入口。PDF等待封面解码，失败使用书名占位。蒸馏模块固定在报告最后，标题为“蒸馏一本书”，常显吸顶导航；只提供复制、Markdown和独立HTML，不提供蒸馏分享图或参考资料区。来源核验仍保存在结果包。

## 首次引导（由助手发出，不在报告中弹窗）

安装完成本身不会执行模型任务。首次调用时用简短提示引导，不重复讲安装过程：

> 年年阅已就绪。可以说“生成我的2026年微信读书报告”，或“打开我已有的阅读报告”。报告生成后，也可以说“蒸馏《书名》，加到报告最后”，或上传电子书。只想整理一本书，可以说“单独蒸馏这本书，生成阅读页”。

年份只是示例，实际默认当前年份。年度报告需要微信读书Skill及用户授权；未授权先引导完成授权，不要求用户重新发送已可用的密钥。单独蒸馏不要求微信读书。

## 年度报告优先

1. 用户说“使用年年阅／生成报告”：采集或复用当前用户、目标年份的微信读书数据；无需先问是否蒸馏。用正式构建器生成报告。
2. 运行以下交付入口开启本机HTTP预览；宿主有浏览器工具时打开返回的 `preview_url`，默认首页是年度报告。不要把HTML作为源码文件打开。用户要外部浏览器时加 `--open`。
3. 简短告知：“报告已打开。想再整理一本书，可以发书名＋作者或上传电子书，我会把精华加到报告最后。”不替用户选择书，不自动开始蒸馏。
4. 保留当前任务的报告绝对路径及年份。后续追加使用这份报告，不扫描其他账号或其他任务的“最近报告”，不把用户数据写入Skill安装目录。

```powershell
python -X utf8 scripts/reading_delivery.py --report <本次报告/index.html> --serve
# 外部浏览器
python -X utf8 scripts/reading_delivery.py --report <本次报告/index.html> --open
```

本地服务需由助手保持运行；页面刷新读取最新文件。服务关闭后，HTML仍可离线浏览，重新预览时恢复本地服务。仅暴露指定HTML，不能把含书籍正文、密钥或中间结果的工作目录直接作为HTTP根目录。

## 后续蒸馏

按轻量流程完成有效 `distillation.json` 后，**交付动作不能只是在对话中贴一段笔记**。

- 当前任务已有报告：直接执行下列追加命令，打开返回URL的 `#ebook`。原有年度数据、书目和其他蒸馏保留；同书名、作者与版本更新该条，不同书或不同版本追加。不要为了追加而重新请求微信读书。
- 当前任务没有报告，或用户明确只要单书：生成独立HTML并打开。不要虚构一个空年度报告，不强制先接微信读书，也不追问是否生成报告。
- 单独蒸馏后又要年报：将已有有效结果作为 `--distillation` 交给报告构建器，随后走年报交付。
- 用户明确只要纯文字时，才按纯文字交付。

```powershell
python -X utf8 scripts/reading_delivery.py --report <本次报告/index.html> --distillation <本次书/deep/distillation.json> --serve
python -X utf8 scripts/reading_delivery.py --distillation <本次书/deep/distillation.json> --output <本次书/阅读页.html> --serve
```

追加前校验结果包；不完整、篡改或真实／示例混用时保留旧报告并说明，不能拿旧书冒充本次完成。追加成功后简短返回预览入口，无需把全文重复贴回对话。用户可自行继续蒸馏或结束。

## 安装验收

发行前使用 `skill_release.py --write-manifest`；安装后 `skill_release.py` 校验资源。用临时新安装目录运行其构建器，以受控数据验证报告、独立页、追加两本、更新同书、保留年度数据及导出入口。比较新安装生成页与源码生成页，不能只打开旧output宣称通过。桌面浏览器测试吸顶、导航悬浮、长标题、缺封面、未知数据、PDF、Markdown及PNG；不把本地验收描述为所有宿主均已实测。
